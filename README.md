# Sobrevivência Low Poly

Jogo de sobrevivência em mundo aberto, low poly, feito na Godot 4.3 (GDScript).

- Etapa 1: jogador em primeira pessoa e terreno
- Etapa 2: biomas e vegetação
- Etapa 3: ciclo de dia e noite + atualização automática

A pasta `atualizacoes/` é o servidor de atualizações: o jogo instalado lê `versao.json`
e baixa o pacote `.pck` quando há uma versão nova.
